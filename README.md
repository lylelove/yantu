# 研图 Yantu

把你正在研究的领域做成一张**待探索的地图**。

你读过的论文会发光，光照到的地方浮现出邻接文献，没照到的地方留在迷雾里。
研究的动作本身就是推开迷雾的动作。

## 它想解决什么

传统文献工具把你已有的文库全部画出来，于是只能回答一个问题：*我读过的东西之间有什么
关系*。但研究者真正卡住的地方是另一个：**我没在看什么**。

列表和全量图谱天生答不了这个——缺失的东西没有行，也没有节点。Yantu 反过来做，默认
隐藏未知，让"看不见"成为界面上一个可见、可操作的状态。

## 核心循环

```
读一篇  →  它点亮  →  照见邻接的陌生文献  →  其中有你没想到的方向  →  读一篇
                ↑                                                      │
                └──────────  写下笔记，照得更远一跳  ←──────────────────┘
```

没有分数，没有等级，没有连续登录天数。唯一的"奖励"是更大的地图。

- **自己导入的文献**永远可见——你的文库属于你。
- **线上拉取的文献**从迷雾开始，只有你读过的东西指向它时才浮现。
- **写笔记**会把已读升级为「灯塔」，比普通已读多照亮一跳。注解是你真的思考过的证据，
  更宽的视野是对思考的回报，不是对点击的回报。

## 上手

```bash
npm install
npm run dev          # Tauri 桌面端
npm run dev:web      # 只跑前端，浏览器打开 localhost:5173
```

首次启动可以点「载入示例地图」，用一份五个方向的真实论文数据立刻看到机制；
也可以直接导入自己的文库。

| 命令 | 作用 |

## 导入

支持 Zotero 导出的 CSV、BibTeX（`.bib`）、RIS（`.ris`）、CSL-JSON / Zotero JSON。
导入前会显示预览：识别多少条、重复多少、跳过哪些以及为什么。原文件只读，不会被修改。

同一篇论文以不同标识符到达（DOI / OpenAlex id / arXiv id）会自动归并成一个节点，
读进度和笔记跟着迁移，不会丢。

## 隐私

- 存档在本地，可随时导出为纯 JSON。
- 联网只发生在你明确点「联网扩展」时，且只发送被扩展的那一个标识符。
- 从不上传你的文库。CSP 把网络请求限制在 `api.openalex.org`。

`src/services/openalex.ts` 顶部的 `CONTACT` 常量是 OpenAlex 礼貌池要求的联系方式，
自用时可以改成你自己的邮箱。

## 技术栈

Tauri 2 + React + TypeScript + Vite，状态用 Zustand，地图是单张 canvas。

核心逻辑（`src/game/`）是纯函数，不认识 React，也不知道数据从哪来：

```
SaveState（持久化）              WorldView（每次推导）
├── papers                       ├── edges       关系
├── progress  已读 + 笔记      →  ├── regions     区域
├── manualEdges                  ├── visibility  迷雾
└── regionNames                  ├── leads       线索
                                 ├── quests      探索任务
                                 └── stats       统计
```

存档只保存推不出来的东西。改评分规则对老存档立即生效，不需要迁移。
