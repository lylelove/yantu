功能详解

每个功能都在回答
「我还不知道什么」

不是功能清单，而是一套让盲区可见、可探索、可讲述的产品机制。

核心机制

迷雾与可见度

五级可见度阶梯：迷雾 → 隐约 → 前沿 → 已读 → 灯塔。光沿强边传播，没照到的地方留在迷雾里——这不是加载状态，而是认知边界的可视化。

  • 导入的文献至少是「前沿」——藏起用户自己的文库等于撒谎
  • 暖琥珀 = 已读，冷青色 = 写了笔记的灯塔
  • 色相表示区域，亮度表示认知深度
已读 灯塔（有笔记） 前沿（未读） 隐约可见
反茧房

线索系统：刻意反推荐

普通推荐按「和你已读有多像」排序——那正是研究者需要逃离的信息茧房。Yantu 把陌生度 + 桥梁性的权重压过相似度。

  • 分数 = 0.45×陌生度 + 0.30×桥梁性 + 0.25×可达性
  • 每条线索必须给出人话理由
  • 最好的线索，是可达但在别处的文献
版图

区域：让「没去过」可以被说出口

区域用可解释的关键词划分，保证稳定且可叙事。界面能说出「『强化学习』你从未踏入过」——一个有名字的空地，才做得到。

  • 可解释：区域名来自语料，用户能复述
  • 稳定：同一份语料永远产出同一批区域
  • beckoning 区域高亮提示待探索方向
探索

探索任务：由地图推导，不存储进度

探索目标完全由当前地图实时推导。局面变了，任务自己消失——无法过期、无法被刷、不需要数据迁移。

  • 无分数、无等级、无连续登录天数
  • 唯一奖励：更大的地图
  • 任务描述直接来自当前盲区形状
详情

论文详情：从地图到深度阅读

点击地图节点打开详情面板。标记已读、写笔记升灯塔、查看引用关系——每个动作都直接改变地图形状。

  • 笔记是唯一的视野增益，点击无回报
  • 可选 OpenAlex 联网扩展（仅发送单条标识符）
  • AI 解读辅助理解（可选）
导入

多格式导入：你的文库属于你

支持 Zotero CSV、BibTeX、RIS、CSL-JSON。导入前显示预览：识别多少条、重复多少、跳过哪些以及为什么。原文件只读，不会被修改。

  • 同一论文不同标识符自动归并（DOI / OpenAlex / arXiv）
  • 读进度和笔记随合并迁移，不会丢
  • 存档可导出为纯 JSON，随时带走

更多能力

语义搜索

搜索标题、作者、主题——只搜索已可见的文献，迷雾中的未知不会被误搜到。

笔记回顾与导出

集中查看所有笔记，一键导出 Markdown。探索过程天然产生叙事线。

本地优先隐私

存档在本机，联网仅在你点「联网扩展」时发生，且只发送单条标识符。文库从不上传。

多存档槽位

不同项目独立存档，随时切换。导出 JSON 备份，数据永远在你手里。

在已点亮的地图范围内快速搜索——找到你想 revisit 的那篇论文
